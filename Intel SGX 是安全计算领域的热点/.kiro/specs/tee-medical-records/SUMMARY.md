## 项目核心目标

### 主要目标
1. **实现数据全生命周期密态保护**
   - 静态保护：数据在磁盘上加密存储
   - 传输保护：数据在网络上加密传输
   - 使用中保护：数据在 Enclave 内处理，外部完全加密

2. **构建硬件级安全隔离**
   - 基于 Intel SGX 的 CPU 级隔离
   - 信任根缩小到 Enclave + CPU 硬件
   - 即使 OS 被完全控制，数据仍安全

3. **实现多用户权限管理**
   - 患者：查看个人信息和病历
   - 医生：查看患者信息，编辑病历
   - 管理员：系统部署和维护

4. **优化系统性能**
   - 使用 Switchless Calls 技术
   - 性能相比传统 ECall/OCall 提升 50%+
   - 支持 100+ 并发用户

## 关键创新点

### 1. 全生命周期密态保护
- 不仅保护静态数据和传输中的数据
- 更重要的是保护使用中的数据
- 数据在 Enclave 内处理，外部完全加密

### 2. 硬件级安全隔离
- 基于 Intel SGX 的 CPU 级隔离
- 信任根从庞大 OS 缩小到 Enclave + CPU
- 即使 OS 被完全控制，数据仍安全

### 3. 性能优化
- 使用 Switchless Calls 技术
- 通过共享内存环形缓冲区减少上下文切换
- 性能相比传统 ECall/OCall 提升 50%+

### 4. 完整的权限管理
- 基于角色的访问控制（RBAC）
- 细粒度权限检查
- 完整的审计追踪

### 5. 法规合规
- 满足《网络安全法》要求
- 满足《数据安全法》要求
- 满足《个人信息保护法》要求
