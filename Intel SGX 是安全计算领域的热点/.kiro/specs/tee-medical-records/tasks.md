# 基于可信执行环境的密态病历信息系统 - 实现任务清单

## 项目概述

本项目采用 C/S 架构，基于 Intel SGX 实现医疗数据的全生命周期加密保护。任务按照从基础到高级、从核心功能到优化的顺序组织。

---

## 第一阶段：项目基础设置与 SGX 环境配置

- [ ] 1. 项目初始化与开发环境搭建
  - 安装 Intel SGX SDK 和相关工具链
  - 配置 Linux 开发环境（Ubuntu 20.04+）
  - 创建项目目录结构（Enclave、App、Common 等）
  - 配置 CMake 构建系统
  - _需求: 1.1, 1.2, 1.3_

- [ ] 2. SGX 基础功能验证
  - 编写 Hello World Enclave 程序
  - 验证 SGX 硬件支持和驱动安装
  - 测试基本的 ECall/OCall 机制
  - 验证编译、签名、运行流程
  - _需求: 1.1_

- [ ] 3. 密码学库集成
  - 集成 OpenSSL 或 SGX-SSL
  - 验证 AES-256-GCM 加密功能
  - 验证 RSA-2048 和 ECC-256 签名功能
  - 验证 HMAC 和 SHA-256 哈希功能
  - _需求: 2.1, 3.1, 4.1_

## 第二阶段：核心安全基础设施

- [ ] 4. 身份认证系统实现
  - 在 Enclave 内实现 RSA/ECC 公钥认证
  - 实现 Challenge-Response 机制
  - 实现 Token 生成和验证
  - 实现 Token 有效期管理
  - 编写单元测试验证认证流程
  - _需求: 1.1, 1.2, 1.3_

- [ ] 5. 基于角色的访问控制（RBAC）实现
  - 定义用户角色（患者、医生、管理员）
  - 实现权限检查函数
  - 实现访问控制矩阵
  - 在 Enclave 内强制执行权限检查
  - 编写单元测试验证权限控制
  - _需求: 1.1, 1.2, 1.3_

- [ ] 6. 密钥管理系统实现
  - 在 Enclave 内实现主密钥生成
  - 实现基于 HKDF 的密钥派生
  - 实现多级密钥体系（主密钥、用户密钥、数据密钥、审计密钥）
  - 实现密钥存储和加载
  - 编写单元测试验证密钥管理
  - _需求: 4.1, 4.2, 4.3_

- [ ] 7. 远程证明（Remote Attestation）实现
  - 实现 Quote 生成
  - 集成 Intel Attestation Service
  - 实现 Quote 验证
  - 实现可信链建立
  - 编写集成测试验证远程证明
  - _需求: 4.1_

- [ ] 8. Sealing 机制实现
  - 实现数据 Sealing（加密和完整性保护）
  - 实现数据 Unsealing（解密和验证）
  - 实现 Sealed 数据的持久化存储
  - 实现系统重启后的数据恢复
  - 编写集成测试验证 Sealing 机制
  - _需求: 4.2, 4.3_
